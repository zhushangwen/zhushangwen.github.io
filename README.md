# zhushangwen.github.io

Personal academic homepage for Shangwen Zhu.

This folder is ready to be used as a GitHub Pages user site. If your GitHub
username is `zhushangwen`, create a repository named:

```text
zhushangwen.github.io
```

Then upload these files to the repository root.

## Local Preview

Open `index.html` directly in a browser.

## Deploy to GitHub Pages

1. Create a public GitHub repository named `zhushangwen.github.io`.
2. Upload `index.html`, `styles.css`, `.nojekyll`, and this `README.md`.
3. Go to repository `Settings` -> `Pages`.
4. Select `Deploy from a branch`.
5. Choose branch `main` and folder `/root`.
6. Save and wait a few minutes.
7. Visit `https://zhushangwen.github.io`.

The public homepage uses your email, GitHub, Kaggle, education, awards, and
research experience from `main.tex`. It intentionally does not show your phone
number, because a public `github.io` page is easily indexed by search engines.
